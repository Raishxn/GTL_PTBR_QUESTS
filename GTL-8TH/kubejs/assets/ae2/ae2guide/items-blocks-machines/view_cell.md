# Display components

<ItemImage id="view_cell" scale="2" />

The display component can filter the display of [terminals.md] and needs to be partitioned in <ItemLink id="cell_workbench" />.

For example, maybe you want a terminal to display only part of the stone building materials. Partition the display components into these materials and load them into the terminal, and the terminal will only display these items.

The effects of display components will be superimposed. For example, if a display component with oak planks and cobblestone is installed, the corresponding equipment will display both.
