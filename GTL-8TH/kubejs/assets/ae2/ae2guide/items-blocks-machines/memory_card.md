# memory card

<ItemImage id="memory_card" scale="4" />

The memory card can copy and paste settings between AE2 [devices] (../ae2-mechanics/devices.md), and can also be connected to [P2P tunnels] (p2p_tunnels.md). It can also copy [upgrade cards](upgrade_cards.md) to the device.

- Shift right click to generate new P2P connection frequency.
- Right click to paste settings or upgrade card, or connect frequency.
