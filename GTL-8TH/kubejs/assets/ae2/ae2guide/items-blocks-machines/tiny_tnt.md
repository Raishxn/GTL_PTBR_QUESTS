#miniTNT

<BlockImage id="tiny_tnt" scale="8" />

Small TNT designed for small explosions. Very useful in the process of making <ItemLink id="quantum_entangled_singularity" /> pairs.

If TNT and Creepers need to be disabled in the server, this item's terrain-breaking effect can be disabled in the config file, allowing singularity pairs to be crafted with terrain-breaking disabled.
