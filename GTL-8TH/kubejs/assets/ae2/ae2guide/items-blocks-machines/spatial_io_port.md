# Space IO port

<BlockImage id="spatial_io_port" p:powered="true" scale="8" />

The spatial IO port is used for [spatial IO](../ae2-mechanics/spatial-io.md), which can be installed with [spatial components](spatial_cells.md) and control spatial IO operations.

The component slots can be extracted or stored by any item logistics device (such as hoppers and AE2 buses) to facilitate automation.
