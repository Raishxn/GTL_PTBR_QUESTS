# Colorizer

<ItemImage id="color_applicator" scale="4" />

The dyer can dye [cables](cables.md), wool, terracotta, glass, concrete and other dyeable blocks. It requires the consumption of [paintballs](paintballs.md) or dye. If you need to wash away the color of the cable or the dye pool on the block, you can put snowballs in it.

It can be charged in <ItemLink id="charger" />.

The dyer behaves similarly to [storage cells](storage_cells.md), which can be placed into the element slot of <ItemLink id="chest" /> to replenish the dye.

Right-click with the dyer in hand to dye, and shift-scroll the wheel to change the current dyed ball and fuel.

## upgrade

The dyer supports the following [upgrade](upgrade_cards.md), which needs to be loaded with <ItemLink id="cell_workbench" />:

* <ItemLink id="equal_distribution_card" /> will allocate equal-sized sectors for each type, that is, a single type cannot fill the dyer
* <ItemLink id="void_card" /> will destroy the input items when the component is full (or a certain type is full when an equalizing card is installed), be careful when setting up partitions!
* <ItemLink id="energy_card" /> can increase its energy capacity
