#Component workbench

<BlockImage id="cell_workbench" scale="8" />

The Component Workbench can be used to configure [storage cells](storage_cells.md) and <ItemLink id="view_cell" />.

You can load [upgrade cards] (upgrade_cards.md) into the component, or configure "partitions" to limit the types of items that the component can store.

If the required item or fluid is not available, drag it from JEI/REI and place it into the filter tank.

Right-clicking on a fluid container (such as a drum or fluid tank) sets the fluid to filter instead of the drum and tank items.

## set up

There are several buttons in the upper left corner of the component workbench:

* Can partition components according to their existing items
* Can clear the partition settings of components
* The component workbench can be set to retain partition settings for easy copying to other components
