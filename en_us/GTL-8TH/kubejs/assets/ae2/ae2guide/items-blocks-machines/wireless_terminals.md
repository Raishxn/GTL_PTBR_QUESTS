# wireless terminal

<Row>
  <ItemImage id="wireless_terminal" scale="4" />

  <ItemImage id="wireless_crafting_terminal" scale="4" />
</Row>

Wireless terminals are portable versions of ordinary wired [terminals](terminals.md). Their UIs are exactly the same, but the wireless terminal only has the [Upgrade Card] (upgrade_cards.md) slot and no <ItemLink id="view_cell" /> slot.

The terminal can be placed into the upper right slot of <ItemLink id="wireless_access_point" /> (with the wireless terminal icon and an arrow below) to pair with the network on which the access point is located.

Only works within <ItemLink id="wireless_access_point" /> range.

It can be charged in <ItemLink id="charger" />.

# wireless terminal

<ItemImage id="wireless_terminal" scale="4" />

A basic terminal, but a portable version! [Network Storage](../ae2-mechanics/import-export-storage.md) can be accessed from anywhere within the scope of <ItemLink id="wireless_access_point" />, or requests can be sent to the [Automatic Synthesis](../ae2-mechanics/autocrafting.md) facility.

# Wireless synthesis terminal

<ItemImage id="wireless_crafting_terminal" scale="4" />

The wireless synthesis terminal is similar to the wireless terminal. Their UI area and settings are the same, but the wireless synthesis terminal has a new synthesis grid that can be automatically supplemented from [Network Storage] (../ae2-mechanics/import-export-storage.md). Be careful when compositing while holding down Shift!
