# Substance Aggregator

<BlockImage id="condenser" scale="8" />

Matter aggregators can be used as trash cans, or to create <ItemLink id="matter_ball" /> and [singularities](singularities.md). It can accept items, fluids, and other things that can be stored in the storage element.

## Settings/Available Recipes

* In destruction mode, the Substance Aggregator will destroy all input items.
* In Matter Ball mode, the Matter Aggregator will create <ItemLink id="matter_ball" /> from the input items. This mode requires storage elements in the top slots of the aggregator. Making a matter ball requires 256 items or 256 barrels of fluid, and <ItemLink id="cell_component_1k" /> (8192-bit capacity) is enough.
* In Singularities mode, the Matter Aggregator will create [Singularities](singularities.md) from input items. This mode requires storage elements in the top slots of the aggregator. Creating a singularity requires 256,000 items or 256,000 barrels of fluid, and <ItemLink id="cell_component_64k" /> (524,288-bit capacity) is enough.
